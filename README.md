# Weather App

A weather website built using HTML, CSS, and JavaScript.

## Features

- Search for a city
- Display temperature
- Display weather condition
- Display humidity
- Display wind speed
- Handle invalid cities
- Loading message
- Celsius/Fahrenheit toggle
- Weather-based background

## Technologies

- HTML
- CSS
- JavaScript
- Open-Meteo API

## How to Run

Open `index.html` in a web browser and enter a city name.
